FIX FOR THE WHITE PAGE

Why the previous deployment was blank:
GitHub Pages was publishing the repository source directly. A Vite + React
project must be built first; browsers cannot run the raw TSX source files.

This package includes .github/workflows/deploy.yml. It builds the project
with `npm run build` and publishes the generated `dist` folder.

UPLOAD:
1. Open your My-Portfolio repository in GitHub.
2. Upload the CONTENTS of this ZIP to the repository root, replacing files
   when GitHub asks. Make sure the hidden `.github` folder is included.
3. Commit the changes to the `main` branch.

PAGES SETTING (IMPORTANT):
1. Repository -> Settings -> Pages.
2. Under Build and deployment, set Source to "GitHub Actions".
3. Save if a Save button appears.

DEPLOY:
1. Open the Actions tab.
2. Select "Build and deploy portfolio".
3. Wait until both build and deploy jobs show green checks.
4. Visit https://gauthamcristiano.github.io/My-Portfolio/
5. Hard refresh with Ctrl + Shift + R if the old blank page is cached.

The site is configured for the exact repository name My-Portfolio.
