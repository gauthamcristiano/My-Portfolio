# Gautham — Personal Portfolio

Minimal, premium personal portfolio built with React, TypeScript and Vite.

## GitHub Codespaces
Run `npm install`, then `npm run dev` to preview.

## GitHub Pages deployment
1. Open repository Settings → Pages.
2. Set Source to **GitHub Actions**.
3. Push changes to `main`; the included workflow builds and deploys the site.
4. Expected URL: https://gauthamcristiano.github.io/My-Portfolio/

## Before publishing
Review every project description and skill in `src/App.tsx`. Add only skills and claims you can confidently discuss. Add verified public project links when available. If you rename the repository, update `base` in `vite.config.ts`.

Project entries are described as concepts, prototypes or student projects where appropriate. Update their status as the work progresses.
